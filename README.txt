1. Create a new GitHub repository and upload everything in this folder (keep the .github folder).
2. Open the repo > Actions > "Build IPA" > Run workflow (or it runs on upload).
3. When it finishes (about 3-5 min), download the "MockWallet-ipa" artifact and unzip it to get MockWallet.ipa.
4. Send MockWallet.ipa to your iPhone and install it with SideStore.
